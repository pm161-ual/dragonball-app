# Dragon Ball App

Proyecto sobre Dragon Ball dividido en dos partes:

- dragonball-laravel: la API, hecha con Laravel 12.
- dragonball-frontend: la web, hecha con Nuxt y Tailwind CSS.

## Cómo arrancarlo

1. Arrancar la API siguiendo el README de dragonball-laravel.
2. Arrancar la web siguiendo el README de dragonball-frontend.

Las dos tienen que estar funcionando a la vez:

- API: http://127.0.0.1:8000
- Web: http://localhost:3000

## Documentación

- [Manual de usuario](ManualUsuario.md): qué puede hacer cada rol en la web.
- [Manual técnico](ManualTecnico.md): instalación, características, base de datos y chatbot.
